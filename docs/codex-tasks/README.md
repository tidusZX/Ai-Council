# Codex Task Queue

Self-contained briefs designed for async execution by **OpenAI Codex Cloud**.

## Workflow

1. Open Codex Cloud
2. Paste the *full contents* of one `NN-*.md` file as the task brief
3. Codex opens a PR against `main`
4. Review the PR in the next Cowork session and merge or iterate

## Why these tasks fit Codex (not Claude here in Cowork)

- **Self-contained**: no cross-app strategic context needed
- **Clear acceptance criteria**: success is testable
- **Low design ambiguity**: the "what" is settled; only the "how" is open
- **Async-friendly**: nothing here needs real-time iteration

For headline features, design decisions, or anything cross-app, keep it in
Cowork with Claude — that's where the project-wide context lives.
